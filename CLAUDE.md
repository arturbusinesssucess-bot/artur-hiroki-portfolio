# artur-hiroki-portfolio

Site estático (HTML/CSS/JS puro, sem build) do portfólio pessoal do Artur.

## Deploy

- Hospedado no Vercel, conectado ao GitHub (`arturbusinesssucess-bot/artur-hiroki-portfolio`), deploy automático a cada push na branch `master`.
- URL: https://artur-hiroki-portfolio.vercel.app
- **Após qualquer alteração de código aprovada pelo usuário, faça `git add` + `git commit` + `git push origin master` automaticamente, sem perguntar antes.** (Instrução explícita do usuário em 2026-08-10.)
- Sempre que mexer em `index.html`, atualize o `?v=<timestamp>` em `styles.css` e `script.js` para bypassar cache.
